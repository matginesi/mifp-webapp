# Conference content sources

This directory is a **placeholder template**. It intentionally does not embed content references from any previous MIFP conference.

When creating a real conference:

- record the official source for scientific scope and descriptive text;
- record the source/license for venue, city and social-event images;
- verify dates, prices, speakers, committees, sponsors and hotel information;
- keep unconfirmed information as `TBC` or `TBD`;
- replace every placeholder before publication using the editor **Content Check**.

Conference-specific references belong in the generated conference folder, not in `TEMPLATE/`.
